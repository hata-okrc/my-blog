# なんで作ったの？

まずは、Webサービスの開発をデプロイまで一通りやってみたかった。

加えて、

- 学習したことなんかをアウトプット
- 書いた記事が少しでも誰かの役に立てば

役に立つといっても、知識をつらつら書くだけでは「AIに聞けばええやん」という時代なので、学んだ知識+@の何かを提供できるよう模索してゆくつもりです。

本記事では、記念すべきブログの初回投稿として、**本ブログの技術構成や設計方針**についてまとめます。
「なぜこの技術を選んだのか」「どんな構成にしているのか」を整理することで、今後の改善や振り返りにも役立てたいと考えています。

---

## 技術まわり

本ブログで使用している主な技術等です。

- **フロントエンド / バックエンド**
  - Next.js（App Router）
- **レンダリング方式**
  - SSG（Static Site Generation）
- **コンテンツ管理**
  - Markdown（`.md` ファイルをプロジェクト内で管理）
- **スタイリング**
  - Tailwind CSS
- **デプロイ**
  - GitHub Pages

ディレクトリ構成は[リポジトリ](https://github.com/hata-okrc/hata-okrc.github.io)を覗いてみてください。
